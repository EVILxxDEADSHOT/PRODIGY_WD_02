# Stopwatch Web Application

This is a simple stopwatch web application built with HTML, CSS, and JavaScript. The application allows users to start, pause, reset, and record lap times.

----------------Features-----------------

- **Start**: Begin the stopwatch timer.
- **Pause**: Pause the running timer.
- **Reset**: Reset the timer and clear lap records.
- **Lap**: Record the current time as a lap.

-----------------Files-----------------------------

- `index.html`: The HTML structure of the application.
- `styles.css`: The styles for the stopwatch.
- `script.js`: The JavaScript logic for stopwatch functionality.

-------------------How to Use-----------------------

1. Open `index.html` in a web browser.
2. Use the buttons to control the stopwatch:
   - Click "Start" to begin the timer.
   - Click "Pause" to halt the timer temporarily.
   - Click "Reset" to reset the timer to `00:00:00` and clear laps.
   - Click "Lap" to record the current time.
